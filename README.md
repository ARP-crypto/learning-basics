Repository (Repo) defination: A project folder containing all your files, code, and version history.Commit: A permanent snapshot or save point of your files at a specific time.Branch: A parallel version of your repository allowing you to work on features without breaking the main code.Pull Request (PR): A proposal to merge changes from one branch into another, allowing for code review.Clone: Downloading a full copy of a remote repository onto your local computer.Push / Pull: Uploading local commits to the cloud or downloading the latest remote changes to your local machine and tools
